# LAB 6 — Registration and Form Validation

Single-screen Flutter registration form.

- Required Full Name and Email.
- Email format validation.
- Hidden password with at least 6 characters.
- Exact password confirmation.
- Required Terms and Conditions checkbox.
- Student, Teacher and Developer roles.
- Validation while typing and on submission.
- Errors displayed under invalid fields.
- Valid form data printed to the debug console.
- Success SnackBar.

After submission, the form stays open.
No navigation or saved registration.
Passwords are not printed.

Run:
    flutter pub get
    flutter run
